🎓 Clase 1.4 ~90 min

Configurando tu entorno de trabajo

Crea cuentas en las plataformas esenciales, entiende los modelos de créditos y precios, organiza tus proyectos y prepárate para empezar a crear.

1

🔑 Crear cuentas en las plataformas esenciales

Configuraremos cuentas en todas las plataformas que usaremos durante el curso. Empieza por las gratuitas y freemium:

1. Kling (klingai.com)

Crea una cuenta gratuita. Recibirás créditos iniciales para generar videos. Explora la interfaz y familiarízate con las opciones de generación de video e imagen. No necesitas una tarjeta de crédito para empezar.

2. Midjourney (midjourney.com)

Crea una cuenta de Discord (si aún no tienes una) y únete al servidor de Midjourney. También visita alpha.midjourney.com para usar la interfaz web. El plan Basic ($10/mes) es suficiente para empezar. No hay un plan gratuito permanente.

3. Runway (runwayml.com)

Crea una cuenta gratuita. Recibirás créditos iniciales para hacer pruebas. Explora los modos de generación de video (Gen-4, Gen-4.5) y las herramientas de edición incluidas.

4. ElevenLabs (elevenlabs.io)

Crea una cuenta gratuita. El plan free ofrece 10.000 caracteres/mes para generar voz. Prueba las voces predefinidas y explora el panel de control.

5. Hugging Face (huggingface.co)

Crea una cuenta gratuita. Allí puedes acceder a FLUX.2 mediante Spaces o descargar modelos para usarlos localmente. También sirve para probar otros modelos open-source.

6. CapCut (capcut.com)

Descarga la aplicación de escritorio (Windows/Mac) o usa la versión web. Es completamente gratuita y tiene funciones de IA integradas. Será nuestro editor principal.

💡 Estrategia para ahorrar

Para el curso, invierte inicialmente solo en Midjourney Basic ($10/mês). Todas las demás herramientas tienen planes gratuitos suficientes para aprender. Cuando estés produciendo contenido real, evalúa qué planes pagos tienen sentido para tu volumen de producción.

4

🖥️ Recomendaciones de hardware

La mayoría de las herramientas que usaremos funcionan en la nube, pero contar con hardware adecuado mejora la productividad:

Para herramientas en la nube (suficiente)

  • • Cualquier computadora con un navegador moderno
  • • 8GB RAM mínimo
  • • Conexión estable a Internet
  • • Monitor Full HD (recomendado)
  • • Almacenamiento: 100GB+ libres para proyectos

Para modelos locales (FLUX, SD)

  • • GPU NVIDIA con 8GB+ VRAM (RTX 3060+)
  • • 16GB+ RAM
  • • SSD con 50GB+ libres para modelos
  • • Python 3.10+ instalado
  • • FLUX.2 klein funciona con 8GB VRAM

⚠️ ¿Sin GPU?

¡No hay problema! Todas las herramientas principales (Kling, Midjourney, Runway, ElevenLabs) funcionan 100% en la nube. Los modelos locales son opcionales y se explorarán como alternativa, no como requisito. También puedes usar Google Colab (gratuito) para ejecutar modelos en la GPU de Google.

5

🔧 Extensiones y consejos de productividad

Extensiones de navegador recomendadas

  • • Loom — graba la pantalla para documentar procesos
  • • Image Downloader — descargar imágenes de interfaces de IA
  • • Dark Reader — comodidad visual para sesiones largas
  • • Tab Manager — organiza las muchas pestañas de herramientas

Apps de apoyo

  • • Notion u Obsidian — documenta prompts que funcionan
  • • ShareX (Windows) / CleanShot (Mac) — capturas de pantalla rápidas
  • • HandBrake — convierte formatos de video (gratis)
  • • Google Drive / OneDrive — copia de seguridad en la nube de los proyectos
6

🎯 Uso estratégico de planes gratuitos

Maximiza lo que puedes hacer gratis con esta estrategia:

  1. 1. Planifica antes de generar — Escribe tus prompts en un documento antes de usar créditos. Cada intento cuenta.
  2. 2. Usa Kling para pruebas de video — Con 66 créditos gratis al día, es la mejor opción para experimentar.
  3. 3. FLUX.2 vía Hugging Face Spaces — Genera imágenes gratis sin instalar nada. Puede haber una cola, pero es gratis.
  4. 4. ElevenLabs gratis para borradores — Usa los 10k caracteres/mes para probar la narración. Graba la versión final cuando estés satisfecho.
  5. 5. Hailuo para volumen — A $0.28/video, es la opción más barata para producir múltiples variaciones.
  6. 6. CapCut es 100% gratis — No escatimes aquí, usa todas las funciones sin restricciones.
