Midjourney V8.1 — Del prompt a la imagen perfecta

Domina Midjourney V7 y conoce V8 Alpha: interfaces, ingeniería de prompts, Draft Mode, Omni Reference y generación de video nativa.

1

🎨 Midjourney V7 — Reconstruido desde cero

Midjourney V7 no fue una actualización incremental: fue una reconstrucción completa del modelo. Lanzado en 2025, introdujo cambios fundamentales en la forma en que Midjourney interpreta y ejecuta prompts.

Interpretación literal de prompts

V7 sigue las instrucciones con precisión. Si pides "3 gatos", recibes exactamente 3 gatos. Las manos, los dedos y la anatomía se renderizan correctamente. Los textos en las imágenes son legibles y precisos.

Renderizado de texto

Por primera vez, Midjourney renderiza texto de forma confiable dentro de las imágenes. Perfecto para logos, pósteres, portadas y material de marketing.

Draft Mode

Genera variaciones rápidas en menor resolución para la exploración creativa. 10x más rápido que el modo normal. Ideal para probar ideas antes de generar en alta resolución.

Omni Reference

Permite usar imágenes de referencia para mantener la consistencia de personajes, estilos y objetos entre múltiples generaciones. Es revolucionario para proyectos con una identidad visual coherente.

✍️ Ingeniería de prompts para Midjourney

El arte de escribir buenos prompts es la habilidad más importante para generar imágenes de calidad. Esta es la estructura recomendada:

// Estructura del prompt

[SUJETO] + [ACCIÓN/ESCENA] + [ESTILO] + [ILUMINACIÓN] + [CÁMARA] + [PARÁMETROS]


// Ejemplo práctico

A Brazilian woman in her 30s sitting at a modern coffee shop,

sipping espresso while reading on a tablet,

warm golden hour lighting through large windows,

photorealistic, Canon EOS R5 85mm f/1.4,

shallow depth of field --ar 16:9 --v 7

Parámetros esenciales

  • • --ar 16:9 — aspect ratio (proporción de la imagen)
  • • --v 7 — versión del modelo (usa 7 para mayor estabilidad)
  • • --stylize 100 — 0-1000, controla cuánto «interpreta» MJ artísticamente
  • • --chaos 20 — 0-100, variación entre resultados
  • • --quality 2 — calidad de renderizado (1 o 2)
  • • --no [item] — elimina elementos no deseados
