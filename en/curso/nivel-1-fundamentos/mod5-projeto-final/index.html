🎓 Module 5

Final Project

Duration: 5-7 hours • 4 lessons

About this module

Final project combining all the tools learned in Level 1. You'll create a 30-60 second video presenting a product or service, combining AI-generated images, AI-generated video, synthetic voice narration, and professional editing in CapCut.

What you’ll produce

A complete 30-60 second promotional video, ready to publish, using only AI tools learned throughout Level 1. This project demonstrates your ability to create professional audiovisual content from start to finish.

  • • CapCut: Editing, effects, and finishing
