🏆 Module 12 • Lesson 2

Final Challenge — Complete Portfolio

Build a professional portfolio that demonstrates all the skills you acquired across all 3 levels of VISION.

⏱️ ~120 minutes 📊 Advanced 🔄 Updated Apr/2026
1

🎯 The Challenge

This is the final challenge of the VISION course. You’ll create a complete professional portfolio that demonstrates your skills in every area covered in the course: image generation, video creation, audio production, automation, and tool development.

Portfolio requirements

Your portfolio should include, at a minimum:

  • ✅ 5 AI-generated images — Using at least 2 different tools (Midjourney, FLUX, DALL-E, etc.)
  • ✅ 3 AI-created videos — Using different tools (Kling, Runway, Hailuo, etc.)
  • ✅ 1 music track — Created with Suno or an equivalent tool
  • ✅ 1 automated workflow — Working pipeline in n8n, Make, or Zapier
  • ✅ 1 vibe-coded tool — A functional app or website created with v0, Replit, Cursor, or similar
2

🖼️ Requirement 1: 5 AI-generated Images

Demonstrate versatility in image generation. Each image should have a clear purpose and demonstrate a different technique.

Image Requirement Suggested tool
Image 1 Photorealistic portrait of a person Midjourney v7 / FLUX
Image 2 Landscape or setting (art style) Midjourney / DALL-E 3
Image 3 Product design or mockup FLUX / Ideogram
Image 4 Image with legible integrated text Ideogram / FLUX
Image 5 Image edited with inpainting or img2img ComfyUI / Photoshop AI

For each image, document:

  • • Tool used and version
  • • Full prompt (or process description)
  • • Generation parameters (aspect ratio, style, seed, etc.)
  • • Number of attempts until the final result
  • • Post-processing applied (if any)
3

🎬 Requirement 2: 3 AI-generated Videos

Demonstrate your expertise in creating videos with different tools. Each video must be at least 15 seconds long.

Video 1: Image-to-Video

Start with a still image and generate a video with motion. Use Kling 3.0 or Runway Gen-4.

Video 2: Text-to-Video

Generate a video from a text prompt alone. Use Hailuo or Seedance.

Video 3: Edited production

Combine multiple AI clips with editing in CapCut. Add captions, transitions, and music.

4

🎵 Requirement 3: 1 Music Track

Create an original music track using AI tools. The music must be at least 1 minute long and demonstrate control over style, mood, and structure.

Music criteria

  • • Minimum duration of 1 minute
  • • Consistent and intentional musical style
  • • Can be instrumental or include lyrics/vocals
  • • Document the prompt and parameters used
  • • Bonus: use the music as a soundtrack for one of your videos
5

⚙️ Requirement 4: 1 Automated Workflow

Demonstrate your automation skills by creating a functional workflow that solves a real content production problem.

Workflow suggestions

  • Repurposing pipeline: Article → posts for 3 social media platforms
  • Automated newsletter: Weekly niche content curation
  • Trend monitor: Detects trending topics and suggests content
  • Video pipeline: Script → voiceover → images → editing
  • Analytics report: Consolidates metrics from multiple platforms

Workflow documentation

Include: a screenshot of the complete workflow, a description of each node/module, required credentials (without actual values), usage instructions, and an output example. Consider exporting the workflow as JSON so others can import it.

6

💻 Requirement 5: 1 Vibe-Coded Tool

Create a functional tool using vibe coding techniques. The app should solve a real problem for content creators.

Tool suggestions

Prompt Generator

Interface where you select a style, subject, and parameters and get an optimized prompt for Midjourney/FLUX.

Editorial calendar

App with a visual calendar for planning weekly content with topic suggestions.

Cost calculator

Calculator that estimates API costs for producing X videos per month with different tools.

Landing page

Professional page for your portfolio or digital product, built with v0 or Replit.

7

📋 Self-Assessment Rubric

Use this rubric to evaluate the quality of your portfolio before publishing it:

Criterion Excellent (5) Good (3) Needs improvement (1)
Visual quality Professional, artifact-free Good, few issues Visible artifacts
Variety of tools 4+ different tools 2-3 tools 1 tool only
Documentation Complete, with prompts and process Partial No documentation
Creativity Original and surprising Good but predictable Generic
Functionality (workflow/app) Works perfectly Works with minor adjustments Doesn't work
Presentation Organized, professional Reasonable Disorganized

Score: 25-30 = Excellent | 18-24 = Good | Below 18 = Refine

If your score is below 18, revisit the relevant lessons and improve the items with low scores. A strong portfolio is your professional calling card.

8

🌐 Publishing Your Portfolio Online

A portfolio that no one sees is useless. Publish it on a professional platform:

Platform Best for Cost
Behance Visual portfolio (images and videos) Free
Notion (public) Complete portfolio with documentation Free
Own website (v0/Replit) Maximum professionalism and control Free–$10/month
GitHub Pages Technical profile + web portfolio Free
9

🤝 Peer Review

Share your portfolio with other VISION students to get constructive feedback. The peer review process improves the quality of your work and helps you develop a critical eye.

How to do a peer review

  1. Share your portfolio link with the VISION community
  2. Review at least 2 portfolios from other students
  3. Use the evaluation rubric to give structured feedback
  4. Be constructive: point out strengths AND areas for improvement
  5. Incorporate the feedback you received and update your portfolio
10

  • I made 3 videos with different AI tools
  • Created 1 AI music track
  • I built 1 functional automated workflow
  • Built 1 tool with vibe coding
  • I documented the entire process and prompts used
  • I evaluated my portfolio using the rubric (score >= 18)

  • I participated in the peer review process
