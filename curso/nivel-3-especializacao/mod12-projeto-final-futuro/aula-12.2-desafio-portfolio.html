🏆 Módulo 12 • Aula 2

Desafio Final — Portfólio Completo

Monte um portfólio profissional que demonstra todas as habilidades adquiridas nos 3 níveis do VISION.

⏱️ ~120 minutos 📊 Avançado 🔄 Atualizado Abr/2026

🎯 O Desafio

Este é o desafio final do curso VISION. Você vai criar um portfólio profissional completo que demonstra domínio em todas as áreas cobertas pelo curso: geração de imagens, criação de vídeos, produção de áudio, automação e desenvolvimento de ferramentas.

Requisitos do portfólio

Seu portfólio deve incluir, no mínimo:

  • ✅ 5 imagens geradas por IA — Usando pelo menos 2 ferramentas diferentes (Midjourney, FLUX, DALL-E, etc.)
  • ✅ 3 vídeos criados com IA — Usando ferramentas diferentes (Kling, Runway, Hailuo, etc.)
  • ✅ 1 faixa musical — Criada com Suno ou ferramenta equivalente
  • ✅ 1 workflow automatizado — Pipeline funcional no n8n, Make ou Zapier
  • ✅ 1 ferramenta vibe-coded — App ou site funcional criado com v0, Replit, Cursor ou similar

🖼️ Requisito 1: 5 Imagens com IA

Demonstre versatilidade na geração de imagens. Cada imagem deve ter um propósito claro e demonstrar uma técnica diferente.

Imagem Requisito Ferramenta sugerida
Imagem 1 Retrato fotorrealista de pessoa Midjourney v7 / FLUX
Imagem 2 Paisagem ou ambiente (estilo artístico) Midjourney / DALL-E 3
Imagem 3 Design de produto ou mockup FLUX / Ideogram
Imagem 4 Imagem com texto legível integrado Ideogram / FLUX
Imagem 5 Imagem editada com inpainting ou img2img ComfyUI / Photoshop AI

Para cada imagem, documente:

  • • Ferramenta utilizada e versão
  • • Prompt completo (ou descrição do processo)
  • • Parâmetros de geração (aspect ratio, style, seed, etc.)
  • • Número de tentativas até o resultado final
  • • Pós-processamento aplicado (se houver)

🎬 Requisito 2: 3 Vídeos com IA

Demonstre domínio na criação de vídeos com ferramentas diferentes. Cada vídeo deve ter pelo menos 15 segundos.

Vídeo 1: Image-to-Video

Parta de uma imagem estática e gere um vídeo com movimento. Use Kling 3.0 ou Runway Gen-4.

Vídeo 2: Text-to-Video

Gere um vídeo apenas a partir de um prompt de texto. Use Hailuo ou Seedance.

Vídeo 3: Produção editada

Combine múltiplos clips de IA com edição no CapCut. Adicione legendas, transições e música.

🎵 Requisito 3: 1 Faixa Musical

Crie uma faixa musical original usando ferramentas de IA. A música deve ter pelo menos 1 minuto de duração e demonstrar controle sobre estilo, mood e estrutura.

Critérios para a música

  • • Duração mínima de 1 minuto
  • • Estilo musical coerente e intencional
  • • Pode ser instrumental ou com letra/vocalização
  • • Documente o prompt e parâmetros utilizados
  • • Bonus: use a música como trilha sonora de um dos seus vídeos

⚙️ Requisito 4: 1 Workflow Automatizado

Demonstre capacidade de automação criando um workflow funcional que resolve um problema real de produção de conteúdo.

Sugestões de workflows

  • Pipeline de repurposing: Artigo → posts para 3 redes sociais
  • Newsletter automática: Curadoria semanal de conteúdo do nicho
  • Monitor de tendências: Detecta tópicos em alta e sugere conteúdo
  • Pipeline de vídeo: Script → voiceover → imagens → montagem
  • Relatório de analytics: Consolida métricas de múltiplas plataformas

Documentação do workflow

Inclua: screenshot do workflow completo, descrição de cada nó/módulo, credenciais necessárias (sem valores reais), instruções de uso e exemplo de output. Considere exportar o workflow como JSON para que outros possam importar.

💻 Requisito 5: 1 Ferramenta Vibe-Coded

Crie uma ferramenta funcional usando técnicas de vibe coding. O app deve resolver um problema real para criadores de conteúdo.

Sugestões de ferramentas

Gerador de prompts

Interface onde o usuário seleciona estilo, assunto e parâmetros e recebe um prompt otimizado para Midjourney/FLUX.

Calendário editorial

App com calendário visual para planejar conteúdo semanal com sugestões de temas.

Calculator de custos

Calculadora que estima custos de API para produção de X vídeos por mês com diferentes ferramentas.

Landing page

Página profissional para seu portfólio ou produto digital, construída com v0 ou Replit.

📋 Rubrica de Autoavaliação

Use esta rubrica para avaliar a qualidade do seu portfólio antes de publicá-lo:

Critério Excelente (5) Bom (3) Precisa melhorar (1)
Qualidade visual Profissional, sem artefatos Boa, poucos problemas Artefatos visíveis
Diversidade de ferramentas 4+ ferramentas diferentes 2-3 ferramentas 1 ferramenta apenas
Documentação Completa, com prompts e processo Parcial Sem documentação
Criatividade Original e surpreendente Bom mas previsível Genérico
Funcionalidade (workflow/app) Funciona perfeitamente Funciona com ajustes menores Não funciona
Apresentação Organizado, profissional Razoável Desorganizado

Pontuação: 25-30 = Excelente | 18-24 = Bom | Abaixo de 18 = Refinar

Se sua pontuação for inferior a 18, volte às aulas relevantes e melhore os itens com nota baixa. Um portfólio forte é seu cartão de visitas profissional.

🤝 Peer Review

Compartilhe seu portfólio com outros alunos do VISION para receber feedback construtivo. O processo de peer review melhora a qualidade do seu trabalho e ajuda a desenvolver visão crítica.

Como fazer peer review

  1. Compartilhe o link do seu portfólio na comunidade VISION
  2. Revise pelo menos 2 portfólios de outros alunos
  3. Use a rubrica de avaliação para dar feedback estruturado
  4. Seja construtivo: aponte pontos fortes E áreas de melhoria
  5. Incorpore o feedback recebido e atualize seu portfólio

  • Desenvolvi 1 ferramenta com vibe coding
