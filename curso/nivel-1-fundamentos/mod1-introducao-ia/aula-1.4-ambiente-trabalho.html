Configurando seu Ambiente de Trabalho

Crie contas nas plataformas essenciais, entenda os modelos de créditos e preços, organize seus projetos e prepare-se para começar a criar.

🔑 Criando Contas nas Plataformas Essenciais

Vamos configurar contas em todas as plataformas que usaremos ao longo do curso. Comece pelas gratuitas e freemium:

1. Kling (klingai.com)

Crie uma conta gratuita. Você recebe créditos iniciais para gerar vídeos. Explore a interface e familiarize-se com as opções de geração de vídeo e imagem. Não precisa de cartão de crédito para começar.

2. Midjourney (midjourney.com)

Crie uma conta no Discord (se ainda não tiver) e entre no servidor do Midjourney. Também acesse alpha.midjourney.com para a interface web. O plano Basic ($10/mês) é suficiente para começar. Não há plano gratuito permanente.

3. Runway (runwayml.com)

Crie uma conta gratuita. Você recebe créditos iniciais para testar. Explore os modos de geração de vídeo (Gen-4, Gen-4.5) e as ferramentas de edição incluídas.

4. ElevenLabs (elevenlabs.io)

Crie uma conta gratuita. O plano free oferece 10.000 caracteres/mês de geração de voz. Teste vozes pré-definidas e explore o painel de controle.

5. Hugging Face (huggingface.co)

Crie uma conta gratuita. É onde você acessa FLUX.2 via Spaces ou baixa modelos para uso local. Também útil para testar outros modelos open-source.

6. CapCut (capcut.com)

Baixe o app desktop (Windows/Mac) ou use a versão web. Completamente gratuito com recursos de IA integrados. Será nosso editor principal.

💡 Estratégia de economia

Para o curso, invista inicialmente apenas no Midjourney Basic ($10/mês). Todas as outras ferramentas têm planos gratuitos suficientes para aprender. Quando estiver produzindo conteúdo real, avalie quais planos pagos fazem sentido para seu volume de produção.

🖥️ Recomendações de Hardware

A maioria das ferramentas que usaremos roda na nuvem, mas ter hardware adequado faz diferença na produtividade:

Para ferramentas na nuvem (suficiente)

  • • Qualquer computador com navegador moderno
  • • 8GB RAM mínimo
  • • Conexão de internet estável
  • • Monitor Full HD (recomendado)
  • • Armazenamento: 100GB+ livres para projetos

Para modelos locais (FLUX, SD)

  • • GPU NVIDIA com 8GB+ VRAM (RTX 3060+)
  • • 16GB+ RAM
  • • SSD com 50GB+ livres para modelos
  • • Python 3.10+ instalado
  • • FLUX.2 klein roda em 8GB VRAM

⚠️ Sem GPU?

Sem problema! Todas as ferramentas principais (Kling, Midjourney, Runway, ElevenLabs) rodam 100% na nuvem. Modelos locais são opcionais e serão explorados como alternativa, não como requisito. Você também pode usar Google Colab (gratuito) para rodar modelos na GPU da Google.

🔧 Extensões e Dicas de Produtividade

Extensões de navegador recomendadas

  • • Loom — gravar tela para documentar processos
  • • Image Downloader — baixar imagens de interfaces de IA
  • • Dark Reader — conforto visual para longas sessões
  • • Tab Manager — organizar as muitas abas de ferramentas

Apps de apoio

  • • Notion ou Obsidian — documentar prompts que funcionam
  • • ShareX (Windows) / CleanShot (Mac) — capturas de tela rápidas
  • • HandBrake — converter formatos de vídeo (grátis)
  • • Google Drive / OneDrive — backup na nuvem dos projetos

🎯 Usando Free Tiers Estrategicamente

Maximize o que você pode fazer gratuitamente com esta estratégia:

  1. 1. Planeje antes de gerar — Escreva seus prompts em um documento antes de usar créditos. Cada tentativa conta.
  2. 2. Use Kling para testes de vídeo — Com 66 créditos/dia gratuitos, é a melhor opção para experimentar.
  3. 3. FLUX.2 via Hugging Face Spaces — Gere imagens gratuitamente sem instalar nada. Pode ter fila, mas é gratuito.
  4. 4. ElevenLabs free para rascunhos — Use os 10k caracteres/mês para testar narração. Grave a versão final quando estiver satisfeito.
  5. 5. Hailuo para volume — A $0.28/vídeo, é a opção mais barata para produzir múltiplas variações.
  6. 6. CapCut é 100% gratuito — Não economize aqui, use todas as funcionalidades sem restrição.
