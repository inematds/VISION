🎓 Módulo 5 • Aula 1

Planejamento do Projeto

Defina o conceito, crie o roteiro e planeje todos os assets do seu projeto final.

⏱️ ~60 minutos 📊 Iniciante 🔄 Atualizado Abr/2026
1

🎯 Definindo o Conceito

O projeto final do Nível 1 consiste em criar um vídeo promocional de 30-60 segundos para um produto ou serviço, usando exclusivamente ferramentas de IA. Antes de produzir qualquer asset, precisamos planejar cuidadosamente.

O que é o projeto final?

Um vídeo promocional completo que combina: imagens geradas por IA (Midjourney/FLUX), clipes de vídeo IA (Kling 3.0/Runway), narração sintética (ElevenLabs v3), música de fundo (Suno v5), tudo editado no CapCut. O resultado deve parecer produzido por uma equipe profissional.

Escolhendo seu produto ou serviço

Escolha algo que você conheça ou tenha interesse. Pode ser real ou fictício. Exemplos:

Produto físico

Fone de ouvido, tênis, cosmético, alimento, gadget

Produto digital

App, curso online, e-book, template, ferramenta SaaS

Serviço

Consultoria, design, fotografia, marketing, café

Marca pessoal

Apresentação pessoal, portfólio, canal do YouTube

Definindo o público-alvo

Responda estas perguntas antes de continuar:

  • Quem é o público? (Idade, interesses, dores, desejos)
  • Onde vai assistir? (TikTok, Instagram, YouTube, LinkedIn)
  • Qual a ação desejada? (Comprar, seguir, conhecer, se inscrever)
  • Qual o tom? (Divertido, profissional, inspirador, urgente)
  • Qual o diferencial? (O que torna esse produto/serviço especial)
2

📝 Criando o Roteiro com ChatGPT

O roteiro é a espinha dorsal do seu vídeo. Vamos usar o ChatGPT para criar um roteiro profissional e estruturado.

Prompt para o ChatGPT

Crie um roteiro para um vídeo promocional de [30/60] segundos
para [descreva o produto/serviço].

Público-alvo: [descreva]
Plataforma principal: [TikTok/Instagram/YouTube]
Tom: [divertido/profissional/inspirador]

O roteiro deve incluir:
1. Hook (primeiros 3 segundos) - algo que prenda atenção
2. Problema que o produto resolve
3. Apresentação da solução
4. Benefícios principais (máximo 3)
5. Call-to-action (chamada para ação)

Formato: inclua timestamps, texto da narração e descrição
visual de cada cena.

Estrutura do roteiro (30 segundos)

Tempo Seção Objetivo Duração
0-3s Hook Prender atenção imediatamente 3 segundos
3-8s Problema Identificar a dor do público 5 segundos
8-15s Solução Apresentar o produto/serviço 7 segundos
15-25s Benefícios Mostrar 2-3 vantagens principais 10 segundos
25-30s CTA Dizer o que o espectador deve fazer 5 segundos

A regra dos 3 segundos

Em redes sociais, você tem exatamente 3 segundos para convencer alguém a continuar assistindo. O hook (gancho) é a parte mais importante do vídeo. Use perguntas provocativas, dados surpreendentes ou imagens impactantes.

3

🎨 Storyboard com IA

O storyboard é a representação visual de cada cena do seu vídeo. Vamos usar o Midjourney para criar referências visuais rápidas de cada cena planejada no roteiro.

Criando o storyboard

  1. Liste as cenas: Baseado no roteiro, identifique cada cena visualmente distinta
  2. Descreva cada cena: Escreva uma descrição visual curta para cada uma
  3. Gere referências: Use o Midjourney para gerar uma imagem de referência por cena
  4. Organize: Coloque as imagens em ordem com as descrições e timestamps

Prompt de storyboard para Midjourney

Use este formato: "storyboard frame, [descrição da cena], [estilo visual], clean composition, --ar 16:9 --v 7". Gere rapidamente em baixa resolução (--quality 0.5) para economizar créditos, pois são apenas referências.

Exemplo de storyboard (vídeo de fone de ouvido)

Cena Tempo Visual Narração
1 - Hook 0-3s Close-up do fone com luz dramática "E se você pudesse ouvir música como nunca antes?"
2 - Problema 3-8s Pessoa no metrô com barulho "Ruído externo arruinando sua concentração?"
3 - Solução 8-15s Pessoa colocando o fone, paz "SonicPro X: cancelamento de ruído inteligente"
4 - Benefícios 15-25s Montagem: academia, café, escritório "40h de bateria. Conforto premium. Design premiado."
5 - CTA 25-30s Produto + logo + link "Garanta o seu. Link na bio."
4

📋 Checklist de Assets

Com o roteiro e storyboard prontos, vamos listar todos os assets que precisam ser produzidos. Esse planejamento evita retrabalho e garante que nada seja esquecido.

🧰 Seleção de Ferramentas

Dependendo do seu projeto, algumas ferramentas serão mais adequadas que outras. Aqui está um guia para escolher a ferramenta certa para cada necessidade.

Necessidade Melhor opção Alternativa gratuita
Imagens fotorrealistas Midjourney v7 FLUX (via Replicate)
Imagens com texto FLUX Ideogram
Vídeo realista Kling 3.0 Pika (versão free)
Vídeo artístico Runway Gen-4.5 Pika
Narração natural ElevenLabs v3 ElevenLabs (free tier)
Música de fundo Suno v5 Suno (free tier) / CapCut library

Planejamento de tempo

Reserve pelo menos 2h para geração de assets (próxima aula), 2h para montagem e 1h para finalização. A geração de imagens e vídeos com IA pode exigir múltiplas tentativas para chegar ao resultado desejado, então não subestime o tempo.

6

✅ Checklist da Aula

  • Escolhi o produto/serviço para o projeto final
  • Defini o público-alvo e a plataforma principal
  • Criei o roteiro com o ChatGPT (hook, problema, solução, benefícios, CTA)
  • Montei o storyboard com referências visuais
  • Listei todos os assets necessários com suas ferramentas
  • Organizei minha pasta de projeto com subpastas
